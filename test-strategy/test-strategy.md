# TEST STRATEGY

## Objective

The objective of this testing is to validate the functionality, usability and reliability of the Automation Exercise web application.

## Testing Approach

The following testing methods will be used:

- Manuel testing
- Exploratory testing
- Edge cases testing
- Negative testing

## Test Levels

- System testing
- Regression testing

## Test Deliverables

- Test Plan
- Test Cases
- Bug Reports
- Edge Cases Documentation
